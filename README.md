# Weekly Bible Study

Static website. Enable GitHub Pages in Settings → Pages → Deploy from a branch → main → / (root).

## Content maintenance
Edit data.json only for routine updates. Studies use ISO dates, passage, title, and questions (text and optional subquestions). Preserve existing studies, deduplicate by date/passage, and sort by date. Events use ISO dates, title, description, and status (confirmed or tentative). Keep uncertain events tentative. Do not publish email headers, addresses, private contact details, or unrelated correspondence. Read attachments for actual questions; never invent missing material. Verify JSON before committing. Check deployment before reporting publication.

Custom domain: smallgroup.robinsonfamily.ca. Configure this in Pages settings and update the existing DNS record only after the new site works.
